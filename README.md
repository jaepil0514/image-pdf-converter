# Universal File Converter

A modern, free online file converter that supports 18+ file formats for images and documents.

## Features

### Image Conversion
- **Supported Formats:** JPG, PNG, GIF, BMP, WebP, SVG, TIFF, ICO
- Convert between any image formats
- Batch processing for multiple files
- High-quality output

### Document Conversion
- **Supported Formats:** PDF, DOCX, DOC, XLSX, XLS, PPTX, PPT, TXT, RTF, ODT
- Convert between document formats
- Preserve formatting and layout
- Batch processing support

### Key Features
- ✅ **100% Free** - No hidden charges or premium features
- ✅ **No Registration** - Start converting immediately
- ✅ **Secure** - Files processed locally, never stored on servers
- ✅ **Fast** - Convert files in seconds
- ✅ **Mobile Friendly** - Works on all devices
- ✅ **Batch Convert** - Process multiple files at once

## Technology Stack

- **Frontend:** React 19 + TypeScript
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **Routing:** Wouter
- **Notifications:** Sonner
- **Build Tool:** Vite

## Getting Started

### Prerequisites
- Node.js 18+
- pnpm or npm

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Build for production
pnpm run build

# Preview production build
pnpm run preview
```
